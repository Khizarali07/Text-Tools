# Text Tools

Small React app built during the Code With Harry course that provides a collection of simple text manipulation utilities (uppercase/lowercase, word count, copy to clipboard, etc.). The app demonstrates basic component structure, controlled inputs and interaction patterns.

## Features

- Convert text to uppercase / lowercase
- Count words and characters
- Remove extra spaces
- Copy result to clipboard
- Simple responsive layout

## Tech

- React (Create React App)
- Plain CSS for styling

## Project structure

- `src/` app entry and components (see `components/`)
- `public/` static assets and `index.html`

## Run locally

```powershell
npm install
npm start
```

## Notes & next steps

- This is a UI-first learning project. To extend it, add unit tests or connect a backend for saving snippets.
